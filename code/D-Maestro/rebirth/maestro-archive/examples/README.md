# Examples — Maestro Executed End-to-End

Each file is a real run: the MoMoney Maestro OS executed on a song concept,
producing a final Suno v4.5 container, show summary, and formatted lyrics.
Files are named by the OS version the run was produced under, so a song's
folder doubles as a record of how the same material was reprocessed as the OS
evolved.

| Song | Style | OS versions run |
|---|---|---|
| `2026-club-banger/` | Hardcore trap cipher / orchestral fusion | v4.2.3, v4.3.0, v4.3.2, v4.4.0, v4.4.1, v4.5.2 |
| `gospel-trap-anthem/` | Gospel-trap, Southern porch-hymn | v4.2.3 (first OS test run) |
| `still-here/` | Southern Gospel Soul | v4.4.0 |
| `contralto-southern-soul/` | Southern Soul / Dancehall Trap | v4.5.5 |

The `2026-club-banger` is the project's primary running example — it was
re-run on nearly every OS release, which makes its folder the clearest way to
see the system's output change version over version.

These artifacts are extracted from the source conversation; the full
deliberation behind each run is in `source/transcript.md`.
