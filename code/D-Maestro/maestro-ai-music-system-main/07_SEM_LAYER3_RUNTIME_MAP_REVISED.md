# SEM LAYER 3 RUNTIME MAP — REVISED

## Identity
Layer 3 is the interwoven SEM runtime.
It is not an after-the-fact scorecard layer.

It is:
- concurrent with Technical UST
- address-bound
- worker-usable
- phase-aware
- controller-visible
- downstream-aware
- compression-aware
- resistance-tested

## Core mission
Determine whether proposed work counts as lawful progress.

## Address binding
Every SEM act binds to:
- axis
- key
- subkey
- issue type
- disposition
- next action

## L3 admissibility functions
### completeness
- assigned address was actually handled
- no required subkey skipped

### integrity
- no truncation
- no false completeness
- no silent null fill

### coherence
- upstream coherence
- downstream coherence
- no cross-axis orphan descriptors
- no address conflict

### quality sufficiency
- relevant SEM dimensions meet viability threshold
- worker can defend result under challenge

### null legality
If unresolved:
- null remains explicit
- rationale is recorded
- dependency is named
- escalation path is defined

### K7 External viability

## Worker-note requirement
Workers must record notes for their choices where judgment is non-trivial:
- why this choice
- what alternative was rejected
- what downstream consequence is anticipated
- what risk remains
- whether the note is same-lane or cross-lane relevant

## Resistance order
### intra-departmental first
Same-lane review occurs before cross-lane escalation.

### interdepartmental second
Cross-lane challenge begins only after same-lane pressure has been applied.

### executive red-pen after that
High-level quality / governance pressure applies after lane-level work and contradiction surfaces are visible.

## Stop-the-line failures
- skipped subkey
- silent null fill
- truncation
- contradiction with locked law
- unresolved blocking dependency
- parser-hostile derivative formatting
- unauthorized lyric change
- false completeness claim

## Controller visibility
Controller may:
- read Layer 3 state
- enforce stop-line outcomes
- gate progression
- detect omission, truncation, skip, and false completeness

Controller may not:
- invent artistic content
- rewrite a weak fill into a passing fill
- replace worker judgment with its own

## Output relation
Layer 3 is the quality bridge between:
- worker labor
- canonical state
- derivative projection
