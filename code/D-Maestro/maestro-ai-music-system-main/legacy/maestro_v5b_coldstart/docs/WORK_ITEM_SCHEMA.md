# Work Item Card Schema — WI.V5B.SCHEMA.V1

## Work Item Fields
- **wi.id:** WI.P{phase}.{axis}.{k_range}.R{round}
- **wi.owner:** Primary owner SME
- **wi.reviewers:** Adjacent reviewers (minimum 2)
- **wi.tie_break:** Default tie-break authority
- **wi.inputs:** Creative UST tags + v0.raw pointers + upstream addresses
- **wi.scope:** Keys/subkeys in range
- **wi.actions:** NULL → value fills; one sentence per subkey
- **wi.required_evidence:** source binding + downstream prediction + challenge cycle + dissent log
- **wi.definition_of_done:** all scoped subkeys non-null AND challenge cycle logged AND handoff notes recorded
- **wi.outputs:** filled subkeys + dissent + tradeoffs + handoff
