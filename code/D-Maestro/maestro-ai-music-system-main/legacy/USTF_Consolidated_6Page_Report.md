# Unified USTF and Template Governance Framework

## Executive Summary
This document outlines a comprehensive system for managing Universal Suno Templates (USTF), personas, and genre-based song generation workflows within modern AI-enhanced music studios. It consolidates practices from prompt engineering, metadata governance, and production design.

## Problem Statement
Current creative workflows in AI-based music production suffer from inconsistent metadata, lack of structure, poor reusability, and insufficient governance around arrangement, theory, and mix.

## Proposed Solution
A structured, role-based USTF governance model that simulates real-world studio workflows, enforces container logic, tracks persona usage, and standardizes genre cards as reusable VST-style assets. It includes automated audits, validator agents, and metadata integrity checks.

## Implementation Plan
1. Normalize all active USTF templates using the provided Skeleton vNext format.
2. Assign studio roles to each container (e.g., Theory → Music Director).
3. Run VAL/QUINN audit passes to ensure structural integrity.
4. Tag and track personas using CREW_TAGS and revenue metadata.
5. Generate genre cards using the research-to-card prompt scaffold.
6. Use FX macros and RoadMap logic for all arrangement modeling.
7. Store all USTFs in a version-controlled workspace (Obsidian or Notion).
8. Reuse genre cards as production plug-ins across Suno sessions.
