#### 12.3 SUB‑AGENT DEFINITIONS (for Audits A & B)

**Buy‑In Score Formula (0–100)**\
`0.25*EmotionalFidelity + 0.20*GenreAuthenticity + 0.20*StructureCohesion + 0.20*PromptFeasibility + 0.15*MixClarity`

- EmotionalFidelity: motif–lyric–vocal alignment to goal.
- GenreAuthenticity: idiomatic chord/feel/instrument choices.
- StructureCohesion: clear sections, transitions, recursion logic.
- PromptFeasibility: Suno‑friendly phrasing, token limit, no hard‑to‑render contradictions.
- MixClarity: stereo plan, frequency lanes, role separation.

On each loop, CriticAgent must print: `score_before → score_after`, top 3 fixes applied, and any unresolved risks.
