# runtime/solution.md — Maestro v5-b (Constrained Runtime Playbook)

## Run entrypoint
1) Store v0.raw (immutable).
2) Phase 0: create dual scaffolds (Creative NULL + Technical NULL).
3) Phase 1: map input into Creative UST (macro/micro), preserve NULLs, create project packet.
4) Phase 2: issue work items per axis; SMEs fill one-sentence constraints per subkey with bindings + downstream predictions; reviewers challenge; dissent logged; tie-break if required.
5) Phase 3: run gates (SEG/G/SE20/CAP/LOCK). If FAIL, stop and emit only diagnostics + missing work items.
6) Phase 4: promote recurring constraints to macro; dedup leaves; compile triad under caps.
7) Phase 5: deliver triad + logs + telemetry.

## No-ambiguity rule
If a requirement conflicts:
- Physics (SEG/LOCK) overrides taste.
- Dissent stays visible until resolved or tie-broken with rationale.
