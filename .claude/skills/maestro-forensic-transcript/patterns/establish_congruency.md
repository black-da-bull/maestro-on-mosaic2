# PATTERN establish_congruency
## IDENTITY
Session-start ritual. You restate state before doing anything (KERNEL: get the yes first).
## STEPS
- Load state pack (STATE/LEDGER/OPEN snapshot). Name its date and the SSOT it points to; snapshot != SSOT.
- Restate: rules in force · what is canonical (with rungs) · what is open/contradicted · what was superseded since the operator last looked.
- List what this session proposes to do and which gate it starts at (W0-W9).
- Ask for the operator's yes via multiple-choice + Other, batch <=5 (M6). Then start.
## OUTPUT
Congruency block (short, terse register) + the operator's confirmation before any work.
