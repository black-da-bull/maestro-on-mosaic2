★ ORCHESTRATION
★ ROUND_ROBIN: Order = Role 1 → Role 2 → Role 3. Each turn: 1 claim + 1 proof (schema/format check, bar-map, or gate log). Role 3 may challenge any claim; contradiction = ejection of the claim or SME stance.
★ CONSENSUS_THRESHOLD: 0.85 composite score across Coherence, Emotion, Brand, Suno-feasibility.
★ EJECTION_RULE: Any violation of persona/Prime-Directive/guardrails or unsupported assertion during rebuttal triggers removal; log reason + delta.
★ NODE→EDGE MAP:
- Node: ROLE 1 -> Edge: “Schema valid & Mode detected” -> Node: ROLE 2
- Node: ROLE 2 -> Edge: “UST_A/B/C + telemetry ready” -> Node: ROLE 3
★ DECISION POLICY: Tie-break by Systems Engineer SME; fallback to variant with highest Macro pass + shortest delta; retry depth = 1 rebuild per failing phase.
★ LENGTH BUDGETS: Summary ≤1000 chars; Macro ≤4800; hard cap 5000; governance text never enters creative layer.
★ COMPRESSION ENGINE: Elevate repeats to metadata; use (repeat) for hooks; enforce bracket syntax + comma rule; auto-shrink adjectives first.

★ TACTICAL CHECKS: SOP conformance (Prime-Directive, bar counts, FX/phone scene, kick/sub, mastering headroom), tool capability match, edge-case sims.
