# 01 — Methodology

Z + A anchored · hindsight pragmatic · backward-primary · recursive decision trees.

## 1. Anchors

**Z (destination) and A (current state) are roots.** Work is defined by the operator's equation: desired outcome − current state ÷ recursive decision trees = work to be performed. Establish Z and A before touching the middle. In session 13 this was made canon as the three-position triangulation (U57): Position 1 = destination (mapped v5.5 + VIG/VIS/SEL), Position 2 = proven anchor (v4.5.5, last WORKING version with proof of function), Position 3 = failure evidence (v5 recreation attempts). "lastly, with this we had where we want to go. where we are. and what fails when one doesn't have the other."

**Hindsight is pragmatic, not bias.** The session ended; the end state is known; use it. Classify proposals mechanically against the end state: survived to canon / superseded at turn N / abandoned at turn M. (Full argument: 03_WHY_AI_DEFAULTS_HERE.md.)

## 2. Reading discipline (operator canon, U13/U22/U41)

- No parse, no chunk-as-units, no skim. Read sequentially in line-bounded chunks (500 lines or operator-specified). Versions are downstream of deltas — never segment by version markers.
- Extract deltas, not features. Delta scales: MACRO / MESO / MICRO / RETROACTIVE / FORWARD. Each speaker issues deltas; structure mutates upstream and downstream.
- Speech acts are delta-carrying units inside council dialogue; deliberation adjacency is a structural relation the pipeline preserves (U33, ratified).
- Authority labels on everything: BASE (operator-issued) / DERIVED (AI-produced) / UNKNOWN. Goal-inference collapse is the dominant failure mode — on drift into parse-mode, STOP and flag.

## 3. Unit of work and evidence shape

- Unit = stratum (round/phase), retaining underlying turn-range + verbatim quotes for audit replay (U4, ACCEPTED).
- Evidence shape per requirement = overlay chain, not single cite: the substrate shows items "overlayed and reenforced" — reinforcement IS the evidence a feature is load-bearing (U20/U53).
- Edges use the six-verb taxonomy: update / upgrade / extend / enhance / exemplify / explain. No extension (correct/amend retired by transported operator F; the tension is preserved in the contradiction register, CR-2).

## 4. Passes (five minimum, bi-directional)

1. Backward-linear from Z with the end state in hand — discovery.
2. Backward-non-linear (follow supersession pointers and lineage jumps).
3. Forward-linear — verification, not discovery.
4. Forward-non-linear (cross-references, relays, recovered segments).
5. Reconciliation — fold; park what does not fit; contradictions to the register, never merged.

Mechanical work precedes interpretation in every pass: split, count, hash, verify coverage with tools (python/), then classify. Never hand-walk what a tool resolves exactly.

## 5. Coverage rules (M4 · M8 · MF-3, all operator-accepted)

- Any chunked parse, summary, or handoff must verify operator-delta survival: per-chunk counts reconciled against full text; mutation IDs enumerated in every handoff.
- Enumerate tool-mediated operator decisions ([mediated], cited via the restating assistant turn, never paraphrased as verbatim) alongside rendered user turns.
- Enumerate operator file-attachment events (export chrome like "file.txt / 2:15 PM") — they are operator acts that do not render as user turns.
- Sweep assistant segments for embedded operator inputs at tails (splitter-defect class REC-A/REC-B); a transcript-within-transcript will show foreign "You said:" markers — classify before counting.

## 6. Session ordering and gating (M9, operative)

- **Calibration first:** validate the frame on one small verifiable case before any corpus-scale pass (canonical example: the Ayo "Run It To Me" covers — operative AND persisted, wrong context).
- **Narrow start:** begin replay with the single most-corrected session; replay + impact map; STOP for operator validation before the full sweep.
- **Rung-naming:** every claim of change names the rung reached — conversational < proposed < accepted < operative < persisted < runtime-enforced — and the dependents touched. No rung, no integration.
- **Persist the metric:** any selection metric (e.g., correction-marker density) ships with its exact marker set and computation, or the selection is not reproducible (lesson MF-2, validated 2026-07-19).

## 7. Fold discipline (mechanical layer — see python/fold_laminate_v0_1.py, extant original)

fold = reduce WITH provenance. One session → one Fold; Folds laminate append-only with under-layers preserved. Invariants, fail-closed: F1 no-flatten · F2 provenance-complete (anti-skeleton: every digest category carries ≥1 source event id) · F3 no-silent-fill · F4 no-silent-merge · F5 root-authority (only ROOT clears a null) · F6 append-only. Never fold this-session's own outputs back in as source — that is circular.

## 8. Session close (M3, the six E's)

Every meaningful session ends with some combination of: Extension · Enhancement · Exemplification · Explanation · Impact propagation · Application re-optimization — then a continuation packet (STATE version + LEDGER delta + OPEN items). State travels as a pack (ATP), not as freeform context; phantom commitments must not leak into the pack (R-RT-PD-01).
