# Round‑Robin SME Protocol — Constructive Elevation Format
Goal: elicit actionable improvements that raise performance, production, and post quality.

## Roles (run all)
1. Systems Architect
2. Production Specialist
3. Vocal Coach
4. Musicologist
5. Algorithmic Bias Auditor
6. Analog Imperfection Specialist
7. Persona Integrity Specialist
8. Trauma‑Aware Analyst
9. Lyrical Quality Checker
10. Format Guardian
11. Negative Control Sheriff

## Procedure
- Each SME evaluates the **entire artifact** independently.
- Apply **Morris Matrix Q1–Q16** with **0.0–5.0** scoring.
- Provide **constructive actions** per domain. No lyric rewriting; critique only.
- Mark **risk axes** and proposed mitigations.
- After all passes, run **Meeting Aggregation** to produce a single scorecard, gating outcome, and prioritized action list.

## Output Template (per SME)
```
SME: <role>
Scores: Q1..Q16 = <values>
Top 3 constructive actions:
- <performance action>
- <production action>
- <post action>
Risks: <axis, mitigation>
Notes: <short>
```

## Aggregation Output
- Averaged Morris Matrix
- Consensus risks and mitigations
- Prioritized Action List (≤7 deterministic changes)
- Integration ledger entries
