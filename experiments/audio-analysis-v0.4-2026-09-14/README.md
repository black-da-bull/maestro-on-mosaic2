## v0.4 trust-boundary repairs

1. Experimental adapter outputs use strict structural contracts; malformed or undeclared fields fail closed.
2. External bridges receive read-only source snapshots instead of preserved source paths.
3. Preserved originals and bridge snapshots are hashed before and after bridge execution; mutation invalidates the run.
4. Fast analysis no longer reports an unmeasured true-peak check as PASS. `AUDIO.TRUE_PEAK.001` is `not_assessed` when true peak was not measured.
5. Deterministic analysis/comparison performs source-hash postchecks.
6. FastAPI audio request models were moved to module scope and endpoint regression coverage was added.
7. Preserved parallel v0.4 work remains archived rather than overwritten; active pytest discovery is scoped to current `tests/`.
