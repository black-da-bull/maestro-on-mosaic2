3. Lock hook/motif and prosody; set meter/key/mode
4. Assemble groove grid and bar roadmap with hinges/drops/lifts
5. Select timbre/FX kit; write performance cues
6. Run council chain: Melody → (Harmony‖Rhythm) → Dynamics → Lyric → Critic
7. Iterate until Critic threshold; patch micro-issues; update ThemeMemory
8. Enforce format/character guards; compress repeated content into metacontainers
9. Translate to executable prompt; build Strict/Loose variants as needed
10. Validate (VAL/QUINN); log to ValidationManifest; record diffs
11. Package exports (zip/manifests); emit session report and ToT meta map
12. Plan next Q-A-F loop; schedule continuity tasks
